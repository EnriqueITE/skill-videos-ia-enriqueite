# Propuestas y contribuciones

El repositorio oficial lo mantiene EnriqueITE. Puedes abrir una incidencia o proponer
un cambio mediante un fork y una pull request. Una propuesta no se incorpora
automáticamente ni concede acceso de escritura al repositorio.

Explica el problema, el cambio y cómo lo has comprobado. Evita incluir claves,
datos personales, perfiles de clientes, voces o material sin permiso.

Las contribuciones que se incorporen se distribuyen bajo GPL-3.0-only, igual que
el proyecto. Debes tener derecho a aportar ese material. No se garantiza la
aceptación de propuestas ni un plazo de respuesta.

Para fallos de seguridad usa el canal privado descrito en [SECURITY.md](SECURITY.md).
